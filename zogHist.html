Your API Keys are Secure

This app is a single self-contained HTML file — no server, no backend, no database. Your API keys for Claude, ChatGPT, and Gemini never leave your browser except in direct calls to their respective AI providers.
🔑
Multiple providers, one key each
You can store separate API keys for Claude (Anthropic), ChatGPT (OpenAI), and Gemini (Google). Each is stored independently in your browser's localStorage and used only when you select that provider. Switching providers does not send your key for the other provider anywhere.
📄
Read the source
Open this file in any text editor. Every line of code is plain readable JavaScript — nothing is minified or hidden. Search for api.anthropic.com, api.openai.com, or generativelanguage.googleapis.com and you will find every outbound call, exactly as written.
🌐
Verify in DevTools
Open your browser's Network tab (F12 → Network). Every request made by this app appears there in real time. You will see only calls to the AI provider you have selected — no other destinations.
💾
Stored locally on your device
Keys are saved in localStorage on your device so you don't have to re-enter them each session. The provider used for each record is also saved and automatically restored when you reopen a record. You can clear keys at any time by deleting them from the input field.
🛡️
How AI providers handle your data
There is an important distinction between consumer AI products (Claude.ai, ChatGPT.com, Google Gemini app) and API access — which is what this app uses. Consumer products may use your conversations to improve their models. API usage generally has stronger privacy protections.
Anthropic (Claude API)
API inputs and outputs are not used for training by default. Logs are retained briefly for safety monitoring then deleted. No opt-in required to avoid training use.
OpenAI (ChatGPT API)
API data is not used for training by default. Zero-data-retention options available for eligible use cases. API terms are contractually distinct from consumer products.
Google (Gemini API)
Free-tier AI Studio usage may be reviewed by humans for safety. Paid API usage through Google Cloud has stronger enterprise data handling commitments. Check which tier you are on.
⚠️ This app cannot guarantee what any provider does with data once received — review each provider's current data processing agreement. For sensitive genealogical data involving living individuals, the paid Anthropic API tier provides the strongest documented protections.
⚠️
One honest caveat
Browser extensions can intercept network requests — that is not something this app controls. For maximum security, use a browser profile without untrusted extensions when working with your API keys.
Calls are billed directly to your account at each provider's standard API rates.  ·  Anthropic  ·  OpenAI  ·  Google
